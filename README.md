🧠 HireLens AI – AI-Powered Resume & Job Description Analyzer

An AI-driven full-stack web application that analyzes a candidate's resume against a job description, generates a match score, identifies skill gaps, and produces personalized interview questions and a preparation plan — built using React, Node.js, Express.js, and the Groq API.

🔗 Live Preview

🌐 Live Website: https://hirelens-ai-1-s7v4.onrender.com/

✨ Key Features

📄 Upload a resume (PDF) and extract text automatically
🧾 Paste or upload a job description for comparison
🤖 AI-powered Resume ↔ JD analysis using LLM (Groq API)
📊 Match score calculation between resume and job description
🧩 Skill severity analysis to highlight missing/weak skills
❓ Auto-generated technical interview questions
🗣️ Auto-generated behavioral interview questions
📝 Personalized interview preparation plan
✅ Structured, validated AI responses for consistent frontend rendering
⚡ Real-time feedback with clean, responsive UI
🛠️ Robust error handling across API and LLM response layers

🛠 Tech Stack

Frontend: React.js, JavaScript, CSS3
Backend: Node.js, Express.js
LLM Integration: Groq API
Resume Parsing: pdf-parse
