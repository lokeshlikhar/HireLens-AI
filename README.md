# 🤖 HireLens AI – AI-Powered Resume & Job Description Analyzer

An AI-powered full-stack web application that analyzes a candidate's resume against a job description using **React.js, Node.js, Express.js, MongoDB, and Groq API**. It generates a match score, identifies skill gaps, creates personalized interview questions, and provides a preparation plan.

## 🔗 Live Preview

**🌐 Live Website:** https://hirelens-ai-1-s7v4.onrender.com/

---

## ✨ Key Features

* 📄 Upload a resume in PDF format and extract text automatically
* 🧾 Paste or upload a job description for comparison
* 🤖 AI-powered Resume ↔ JD analysis using Groq API
* 📊 Generate a match score between resume and job description
* 🧩 Identify missing and weak skills with severity levels
* ❓ Generate personalized technical interview questions
* 🗣️ Generate personalized behavioral interview questions
* 📝 Generate a personalized day-wise interview preparation plan
* ✅ Validate structured AI responses for consistent frontend rendering
* ⚡ Clean and responsive user interface
* 🛡️ Robust error handling for API and LLM responses

---

## 🛠 Tech Stack

* **Frontend:** React.js, JavaScript, CSS3
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, MongoDB Atlas
* **AI / LLM:** Groq API
* **Resume Parsing:** pdf-parse
* **Validation:** Schema-based response validation
* **API Communication:** REST APIs, Axios / Fetch
* **Deployment:** Render
